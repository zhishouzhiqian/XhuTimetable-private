# 隔离签名诊断

仅用于 Android 本机离线排错，**不是独立签名实现**。依赖已安装的天猫校园 APK 类及用户提供的同版本 APK 中的四个安全原生库，不能集成到西瓜课表产品构建。

`AndroidManifest.xml` 没有 `INTERNET` 权限。探针不发 HTTP 请求、不启动官方 App、不输入手机号，也不读取 HAR 旧设备标识或会话。探针重定向 Java Context 的私有目录和 SharedPreferences 到自己的目录；私有原生组件的完整内部行为没有经过审计。

构建入口：

```powershell
py tools/build_tmall_offline_probe.py --apk '<用户提供的 APK>' --har '<首次启动 HAR>' --sdk '<Android SDK>'
```

脚本只从 HAR 取应用标识、协议版本、渠道与功能配置。使用新生成的合成 UTDID、不设置设备 ID 或账号会话，并通过 `RequestSnapshot.freeze` 固定参数。合成 UTDID 仅用于排错，不代表官方设备注册已通过。

产物放入 Git 忽略的 `build/tmall-contract-probe/<随机目录>/`。签名使用独立的临时证书；成功构建后删除临时密钥，不读取项目签名。安装运行需明确指定当前测试模拟器；构建脚本不会自行安装或启动。

默认只保存脱敏 `files/report.json`：是否成功、失败阶段、异常类型、安全错误码、字段长度与相等性结果，不输出签名串、令牌或完整异常堆栈。显式使用 `prepareCandidate=true` 启动时，会额外把本次新生成的原始安全字段、冻结参数和 SDK 编码预览暂存在应用私有 `files/candidate.json`，供本机验收器核对；这不是 HAR 旧数据。诊断完成后卸载探针会删除该私有文件。临时构建目录含官方库，必须留在 Git 忽略范围内，不得提交。

验证内容：

- 原生 SDK 在当前隔离上下文中能否返回四个非空安全字段。
- 对同一份原始字段，SDK 的 `buildRequestHeaders` 与本地 Java 编码预期是否一致。
- 固定其他显式输入、更改时间戳后，签名是否不同。组件内部状态可能变化，不能当作严格密码学单变量证明。
- 冻结正文是否保持不变。

这些结果不验证服务端签名，不验证注册设备或账号身份，也不提供可复用登录态。即使全部通过，仍须另行验证全新的匿名请求，之后才可能研究新短信登录。

## 一次匿名网络验收

`tools/verify_tmall_anonymous_once.py` 是独立的本机发送器，不加载私有安全组件。它只允许向固定主机的公开配置 API 发一次 GET：先从探针私有文件读取新候选内容到内存，检查快照不超过 120 秒、正文为空对象、字段集合和编码与契约一致，再排他创建本地尝试标记并发送。拒绝 Cookie、账号会话、其他 API、额外查询参数和不一致的安全字段。

必须显式传入 `--send-once`、ADB 路径、模拟器编号和尝试标记路径。发生超时或失败也不重试、不跟随跳转、不保存响应 Cookie；相同标记不可再次发送。输出仅含是否尝试、HTTP 状态与允许列表中的业务码。真实网络调用不要放进自动化测试；测试使用伪连接。

这一分离保证签名探针仍无网络权限，避免私有安全组件自行联网。返回 `SUCCESS` 只证明该新匿名请求被服务端接受，不证明独立签名、设备注册或登录已实现。

## 设备注册与复用验收

构建时显式加 `--register --serial <模拟器编号>`，会以本次新合成 UTDID、当前模拟器品牌/型号准备注册正文。`c2`～`c6` 留空，不采集 IMEI、IMSI 或设备序列号；业务 ID 为 SDK 使用的 `4099`。API 名先转小写再进入签名参数，不能直接使用请求对象构造函数中的混合大小写名称。

`verify_tmall_registration_cycle.py` 是单独的显式网络入口：默认不运行，指定 `--send-once` 后最多发一次注册和一次使用新设备 ID 的配置查询。失败即停止；每一阶段有独立排他标记，不自动重试。只有注册成功且返回结构符合预期，才将 ID 在内存中传给下一阶段；签名前参数、SDK 转换头与本次响应 ID 必须一致。

通过固定 ADB 指令将新快照写入探针私有目录，ID 不进入命令参数、输出或源码。再次启动探针仅生成新的签名，仍无网络权限；本机发送器完成查询。运行结束应卸载探针，清除私有的候选请求和注册结果。此验收流程不能查询本人资料、发送短信、下单或启动设备。
